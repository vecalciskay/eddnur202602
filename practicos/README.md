## Reglas de la presentación

* La presentación es individual.
* Para verificar si es su código se le pedirá que puedan realizar a mano algunas partes clave
* Los prácticos tienen logs (Log4j2). El práctico que no tenga logs tiene 0.

Niveles de tipos de errores:

DEBUG / INFO / WARN / ERROR 

Los logs deben tener **contexto**: qué objeto, qué operación, qué datos importan.
No alcanza `logger.info("ok")`.

## Estructuras propias

Listas, pilas, colas y árboles las implementan ustedes.
No se usa `java.util.LinkedList`, `ArrayList` ni `Stack` para la estructura
que es el tema del práctico.
